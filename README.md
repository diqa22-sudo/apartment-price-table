# 아파트 사전점검 단가표 자동 생성기 (Streamlit 웹페이지)

구글 시트에서 행을 복사해 웹페이지에 붙여넣고 버튼 하나만 누르면, 평형
개수에 맞춰 자동으로 세로 길이가 조절된 단가표 이미지를 만들어주는
웹앱입니다. (예전 슬랙 봇 버전을 서버 없이 쓸 수 있는 무료 웹페이지로
바꾼 버전입니다. 이미지를 만드는 핵심 로직은 전혀 바뀌지 않았습니다.)

## 1. 무엇이 들어있나요

| 파일 | 역할 |
|---|---|
| `app.py` | Streamlit 웹페이지 본체 (실행하는 파일) |
| `parser.py` | 붙여넣은 시트 데이터를 읽는 부분 |
| `renderer.py` | 이미지를 조립하고 글자를 그려 넣는 부분 (좌표/폰트 로직 그대로) |
| `config.py` | 글자 위치·크기·색상 설정 (필요시 숫자만 조절) |
| `test_render.py` | 웹페이지 없이 터미널에서 결과 이미지를 미리 확인하는 테스트 도구 |
| `assets/` | 1~5번 템플릿 이미지 + Pretendard 폰트 |

## 2. 처음 실행하기

1. 필요한 프로그램 설치 (최초 1회):
   ```
   pip install -r requirements.txt --break-system-packages
   ```
2. 웹페이지 실행:
   ```
   streamlit run app.py
   ```
3. 실행하면 자동으로 브라우저가 열리거나, 터미널에 뜨는 주소
   (`Local URL: http://localhost:8501`)로 직접 접속하면 됩니다.
4. 이 터미널 창을 닫으면 웹페이지도 함께 꺼집니다. 내 컴퓨터에서만 잠깐
   쓸 거라면 이 상태로 충분하고, 팀원들과 링크로 계속 공유하고 싶다면
   아래 "3. 무료로 인터넷에 배포하기"를 참고하세요.

## 3. 무료로 인터넷에 배포하기 (선택)

내 컴퓨터를 계속 켜두지 않고 다른 사람들도 링크로 접속할 수 있게
하려면, **Streamlit Community Cloud**(streamlit.io, 무료)를 쓰는 게
가장 간단합니다.

1. 이 폴더를 GitHub 저장소에 올림
2. https://streamlit.io/cloud 접속 → GitHub 계정으로 로그인 →
   "New app" → 방금 올린 저장소 선택, 실행 파일로 `app.py` 지정
3. Deploy 클릭 → 잠시 후 `https://xxxx.streamlit.app` 형태의 링크가
   생성됨. 이 링크를 팀원들에게 공유하면 누구나 접속해서 바로 사용
   가능 (컴퓨터를 켜둘 필요 없음)

## 4. 사용 방법

1. 웹페이지에 접속
2. 구글 시트에서 원하는 행(들)을 복사 (Ctrl+C)
3. 웹페이지의 입력창에 붙여넣기 (Ctrl+V)
4. **"이미지 생성하기"** 버튼 클릭
5. 화면에 완성된 단가표 이미지가 뜨고, 아래 **다운로드** 버튼으로
   PNG 파일을 저장할 수 있습니다

예시 입력:
```
힐스테이트메디알레	OO건설	프리미엄	20	51	304,500	239,000	-	191,000	376,000	-	-	276,000
힐스테이트메디알레	OO건설	프리미엄	24	59	333,500	249,000	-	199,000	384,000	-	-	284,000
```

- 헤더(컬럼명) 줄은 넣지 않아도 되고, 실수로 넣어도 자동으로 무시됩니다.
- 몇 개의 평형(행)을 붙여넣든 상관없이 이미지 세로 길이가 자동으로 맞춰집니다.
- 구글시트 셀 안에 줄바꿈이 있거나(예: 단지명이 두 줄), 단지명이 첫 줄에만
  적혀 있어도 자동으로 인식합니다.

## 5. 결과 이미지 위치/폰트가 살짝 어긋나 보인다면

터미널에서 바로바로 확인하면서 조절할 수 있습니다.

```
python3 test_render.py --grid
```

- `output.png`: 완성된 결과 미리보기
- `output_grid.png`: 50px 간격 눈금이 함께 그려진 버전 (좌표 확인용)

`output_grid.png`를 열어서 글자가 들어가야 할 위치의 (x, y) 눈금 값을
읽은 뒤, `config.py` 안의 좌표 숫자(`COMPLEX_NAME_POS`, `ROW1_COL_X`,
`ROW2_COL_X` 등)를 그 값으로 바꾸면 됩니다. 글자 크기는 각 `*_FONT_SIZE`
값을, 자간(글자 사이 간격)은 `*_LETTER_SPACING` 값을 조절하면 됩니다
(음수일수록 글자가 더 붙어 보입니다).

### Figma 디자인과 맞추고 싶다면

Figma Dev Mode(상단 `</>` 아이콘 또는 `Shift+D`)를 켜고 텍스트 레이어를
클릭하면 우측 Inspect 패널에 `font-family`, `font-size`, `font-weight`,
`color`, `letter-spacing` 등이 CSS로 표시됩니다. 그 화면을 스크린샷으로
캡처해서 전달해주시면 `config.py` 값을 실측치로 바로 맞춰드릴 수 있어요.

## 6. 시트 컬럼 구성이 바뀌었다면

`config.py` 맨 아래 `COL_IDX` 표에서, 사용하는 컬럼이 A/B/C... 중 몇 번째
컬럼인지 숫자(0=A, 1=B, 2=C ...)만 수정하면 됩니다. 코드의 다른 부분은
건드릴 필요가 없습니다.

- `정가` 칸에는 G열이 아니라 **타임특가(I열)와 동일한 값**이 표시됩니다
  (원본 디자인 기준이 그렇게 되어 있어요).
